# Docs for Modal

Modal is a component that displays content in a modal dialog with confirm and cancel actions.

It expects the following props:
- `onConfirm`: Function to call when the confirm button is clicked
- `onCancel`: Function to call when the cancel button is clicked
- `children`: ReactNode representing the content to display in the modal body

The Modal component includes a close button in the top-right corner and a confirm button at the bottom. 
It leverages the Button component for both action buttons.
