# Docs for Card

Card is a display component that shows content in a card format with a title, image, and description.

It expects the following props:
- `title`: String for the card heading
- `description`: String for the descriptive content
- `imageSrc`: String containing the image source URL

The Card component uses Next.js's optimized Image component for improved performance and loading experience.
