# Docs for Button

Button is a simple interactive component that renders a standard HTML button element with customizable behavior.

It expects the following props:
- `label`: String text to display on the button
- `onClick`: MouseEventHandler to be triggered when the button is clicked
- `disabled`: Boolean indicating whether the button should be in a disabled state
